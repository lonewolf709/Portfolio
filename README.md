# Samad Gour - Portfolio

A responsive student portfolio built with plain HTML, CSS and JavaScript. No frameworks or build step.

**Live demo:** https://lonewolf709.github.io/Portfolio/

## What it shows
- Dashboard: profile and intro, quick stats, academics, goals, CGPA ring and contact links
- Skills (tap a skill to see the projects behind it), projects and certificates
- Resume download and a contact form
- Light mode (gray and forest green) and dark mode (blue)

## Files
| File | Purpose |
|---|---|
| `index.html` | The whole portfolio (page, styles and data) |
| `Snapchat-1134356047.jpg` | Your profile photo. To use another photo, change the `photo` name in the `BAKED` data in `index.html`. Initials show if it is missing |
| `resume.pdf` | Your resume. The Download resume button appears once this file exists |

## How to run
Open `index.html` in a browser, or publish with GitHub Pages: Settings, Pages, Deploy from a branch, `main` and `/ (root)`.

## Editing
Open the page with `?edit` at the end of the link (for example `.../index.html?edit`) to show the edit buttons.
Edits are saved in that browser only. To change what everyone sees, update the `BAKED` data near the top of the script in `index.html`.

## Built with
HTML, CSS and vanilla JavaScript. Fonts: Poppins (Google Fonts).
